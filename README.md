# CSV Workbench

**毎月の売上CSV整理を、画面操作でまとめて処理。** 店舗や部署から届く複数のCSVを、手作業でコピーして1つにまとめ、重複を探し、合計を計算する作業を減らせます。CSV Workbenchは、同じ列構成のCSVを結合・整理し、必要な項目ごとの合計を別ファイルに出力するWindows向けツールです。

入力ファイルは変更しません。操作は画面上で行えますが、利用にはPython 3.10以降のインストールが必要です。

## 解決できる問題

- 毎月複数のCSVを開き、行をコピーして1つにまとめている。
- データが重複していないか、目で確認している。
- 都道府県や商品カテゴリごとの売上を手計算している。
- 同じ形式のCSV整理を繰り返している。

同じ見出し・列順のCSVであれば、ファイルやフォルダを選んで処理内容を指定し、結合後のCSVと必要に応じた集計CSVを保存できます。

## 主な機能

| できること | 業務での使い方 |
| --- | --- |
| 複数CSVの一括読み込み・結合 | 店舗や部署から届いたCSVを1つにまとめる |
| 全列が同じ重複行の削除 | 同じデータの二重計上を防ぐ |
| 空欄の維持・補完・行の除外 | 欠けたデータを決めた方法で扱う |
| 指定列での並び替え | 商品名や金額など、確認しやすい順にする |
| 数値列の合計・グループ別集計 | 都道府県・商品カテゴリ・担当者ごとの売上を出す |
| 別名でのCSV保存 | 元データを残したまま結果を受け取る |

CSVの文字コードはUTF-8とCP932に対応しています。処理できないCSVや不正な数値は、原因を示して停止します。

## こんな用途に使えます

- 店舗別の売上CSVを月次でまとめる。
- 複数部署の同じ形式のデータを統合する。
- 行が完全に同じデータを削除してから集計する。
- 都道府県、商品カテゴリ、担当者などの列ごとに売上を合計する。
- 毎月繰り返すCSV整理の手順を、同じ画面操作で進める。

## 利用例

同梱の `examples/sales_01.csv` と `examples/sales_02.csv` は、それぞれ**見出しを含めて3行・10列**の架空の注文データです。同じ注文が1行重複しています。重複削除をオンにし、空欄は `keep`、並び替え列は空欄、合計列を「金額」、グループ列を「店舗」にすると、4行の入力から3行が残り、集計結果は大阪店200・東京店250になります。出力先は入力フォルダとは別に指定してください。

## Windowsでの使い方

1. [Python公式サイト](https://www.python.org/downloads/windows/) からPython 3.10以降をインストールします。インストール画面の「Add python.exe to PATH」を有効にしてください。
2. このリポジトリをZIPでダウンロードし、**展開**します。
3. 展開したフォルダ内の `start_windows.bat` をダブルクリックします。「CSV Workbench」の画面が開けば起動成功です。Pythonの `>>>` だけが表示されたら起動していません。`exit()` で終了し、展開したフォルダ内でコマンドプロンプトを開いて `py -3 app.py` を実行し、エラーを確認してください。Pythonのインストール時にTkinterを除外しないでください。
4. 「フォルダを選択」で直下のCSVを一括指定するか、「ファイルを選択」で複数ファイルを指定します。選択し直すと前の選択と入れ替わります。
5. 空欄・重複・並び替え・集計の設定と保存先を選び、「処理を実行」を押します。合計列を選んだ場合は集計CSVも同じ保存先に作成します。

まず `examples` フォルダで試せます。フォルダ選択を使う場合、**出力先を入力フォルダの外にしてください**。入力フォルダ内に保存すると、次回の一括読み込みで出力CSVも対象に入ります。

## 出力ファイルの説明

- `result.csv` のように指定した名前の**結合CSV**：入力CSVの列を使い、各行を1つにつないだ結果です。同じフォルダならファイル名順に読み込み、各CSV内の行順を保ちます。異なるフォルダから個別選択した場合はファイルのパス順です。空欄処理の後、重複削除がオンなら全列が同じ行の2件目以降を除き、先に出てきた行を残します。指定列で並び替える場合だけ行順が変わります。日付順や都道府県順への自動整列はありません。
- `result_summary.csv` のように名前の末尾に `_summary` が付く**集計CSV**：合計列を選んだ場合のみ作成します。結合・整理後の行から数値列を合計します。グループ列を「都道府県」にすると都道府県ごとの合計が出ます。グループ設定は結合CSVの行順や内容を変えません。

上のサンプルを並び替えなしで処理すると、結合CSVは「東京店・りんご・100」「大阪店・みかん・200」「東京店・バナナ・150」の順に3行になります。集計CSVは大阪店200・東京店250です。

## 詳細仕様

| 項目 | 動作 |
| --- | --- |
| 対象 | フォルダ直下の `.csv`（大文字拡張子も可）、または選択した複数ファイル。同じフォルダならファイル名順、別フォルダ混在ならパス順。サブフォルダは対象外です。 |
| 列 | 全ファイルで見出しの名前と順番が一致する必要があります。見出しの空欄・重複、見出しと列数が異なる行はエラーになります。 |
| 文字コード | 入力はUTF-8（BOMあり・なし）を先に試し、読めない場合はCP932を試します。出力はExcelで開きやすいUTF-8 BOM付きです。 |
| 空欄 | `keep`：そのまま。`fill`：空欄・空白のみのセルを指定文字に置換。`drop`：1セルでも空欄・空白のみならその行を除外。 |
| 重複 | 空欄処理の後、全列が完全一致する行の2件目以降を削除します。 |
| 並び替え | 指定列で昇順・降順。数値順を選ぶと数値として並べ、空欄は末尾に置きます。選ばない場合は文字順です。 |
| 合計 | 整理後の行を対象に指定した数値列を10進数で加算します。グループ列は任意です。数値列の空欄は合計に加えず、文字やNaNはエラーになります。 |
| 保存 | 入力CSVは変更せず、既存の出力ファイルは上書きしません。入力ファイルを出力先にも指定できません。出力先と同じフォルダ内の一時ファイルから保存し、ハードリンクを作成できない保存先ではエラーになります。 |

表計算ソフトで数式として実行されやすい文字列（`=`、`+`、`@`、数式に見える `-` などで始まるセル）は、先頭に `'` を付けて出力します。この保護のため、それらのセルは入力と完全に同じ文字列にはなりません。通常の負の数値はそのままです。

## 制限事項・納品前の確認

- `.xlsx` は直接読み込めません。ExcelからCSV形式で保存したファイルが対象です。
- 見出しや列順が異なるファイルの自動変換・統合はしません。先に列構成を揃えてください。
- 全行をメモリに保持するため、非常に大きいファイルはメモリ不足になる場合があります。
- 納品前に、顧客のCSVの少量コピーで列名・文字コード・集計結果を確認し、Windows実機でGUI操作を確認してください。個人情報を含むCSVをGitHubにアップロードしないでください。
