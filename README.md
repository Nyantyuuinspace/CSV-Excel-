# CSV Workbench

複数のCSVをまとめて結合・整理・集計する、Windows向けのデスクトップツールです。Python標準ライブラリだけで動きます。入力CSVは編集せず、処理結果を別名で保存します。

## Windowsでの使い方

1. [Python公式サイト](https://www.python.org/downloads/windows/) からPython 3.10以降をインストールします。インストール画面の「Add python.exe to PATH」を有効にしてください。
2. このリポジトリをZIPでダウンロードし、展開します。
3. ZIPを必ず展開してから、`start_windows.bat` をダブルクリックします。`CSV Workbench` という画面が開けば成功です。Pythonの `>>>` だけが表示されたらツールは起動していません。`exit()` で終了し、展開したフォルダ内でコマンドプロンプトを開いて `py -3 app.py` を実行し、表示されたエラーを確認してください。Pythonのインストール時にTkinterを除外しないでください。
4. 「フォルダを選択」で直下のCSVを一括指定、または「ファイルを選択」で個別に指定します。どちらも選択し直すと入れ替わります。
5. 処理内容と保存先を選び、「処理を実行」を押します。合計列を選んだ場合、`出力名_summary.csv` も同じ場所に作成します。

`examples` フォルダを選び、重複削除と「金額」の合計を指定すれば動作確認できます。集計列に「区分」を選ぶと区分ごとの合計になります。

## 処理のルール

| 項目 | 動作 |
| --- | --- |
| 対象 | フォルダ直下の `.csv`（大文字拡張子も可）、または選択した複数ファイル。ファイル名順に読み込みます。サブフォルダは対象外です。 |
| 列 | 全ファイルで見出しの名前・順番が一致する必要があります。見出しの空欄・重複、列数の異なる行はエラーです。 |
| 文字コード | 入力はUTF-8（BOMあり/なし）→CP932の順に試します。出力はExcelで開きやすいUTF-8 BOM付きです。 |
| 空欄 | `keep`: そのまま。`fill`: 空欄・空白のみのセルを指定文字に置換。`drop`: 1セルでも空欄・空白のみならその行を除外。 |
| 重複 | 空欄処理の後で、全列が完全一致する行の2件目以降を削除します。 |
| 並び替え | 指定列で昇順・降順。数値順を選ぶと数値として並べ、空欄は末尾に置きます。数値順を選ばないと文字順です。 |
| 合計 | 整理後の行を対象に、指定した数値列を正確な10進数で加算します。グループ列は任意。数値列の空欄は0として扱い、文字やNaNはエラーです。 |
| 保存 | 既存ファイルは上書きせず、入力ファイルを出力先にすることもできません。出力先と同じフォルダ内の一時ファイルから保存します。ハードリンクを作成できない保存先ではエラーになります。 |

表計算ソフトで数式として実行されやすい文字列（`=`、`+`、`@`、数式に見える`-`などで始まるセル）は先頭に `'` を付けて出力します。この保護のため、これらのセルは入力と完全に同じ文字列にはなりません。通常の負の数値はそのままです。

## 納品時の確認

- 顧客のCSVを少量コピーして列名・文字コード・集計結果を確認してください。個人情報を含むCSVはGitHubにアップロードしないでください。
- 1ファイルでも異なる列構成の場合は事前に整えてください。`.xlsx` の直接読み込みは未対応で、ExcelからCSV形式で保存したファイルが対象です。
- 全行をメモリに保持するため、非常に大きいファイルはメモリ不足になる場合があります。
- Windows実機でのGUI操作は納品前に確認してください。

開発者向け: リポジトリ直下で `python -m unittest discover -s tests -v` を実行すると処理本体を検証できます。
